# SQL Portfolio

This repository contains SQL queries organized by topic. It demonstrates a range of SQL skills from basic filtering to advanced subqueries.

---

## Files & Sections

1. **01_basic_filtering.sql**  
   Queries demonstrating basic `SELECT`, `WHERE`, `LIKE`, `IN`, `NULL`, and simple filtering operations.  

2. **02_aggregations.sql**  
   Queries demonstrating aggregation functions (`SUM`, `COUNT`, `AVG`, `MIN`, `MAX`) and filtering aggregated results with `HAVING`.  

3. **03_joins.sql**  
   Queries demonstrating `JOIN`, `LEFT JOIN`, filtering after joins, and aggregation with joins.  

4. **04_self_joins.sql**  
   Queries showing self joins on tables such as employees, products, and matches. Includes practical use cases like finding managers, colleagues in the same department, and items with the same price.  

5. **05_subqueries.sql**  
   Queries demonstrating both correlated and uncorrelated subqueries, including comparisons within groups and calculations based on other rows.

---

## Notes

- Tables used are a mix of **common tutorial tables** (`world`, `goal`, `game`, `eteam`, `employees`, `products`)  
- All queries have comments explaining what they do. 
- The subqueries section shows how I practiced comparing rows within groups and independent queries.
