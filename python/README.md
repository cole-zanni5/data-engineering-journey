# Python Portfolio

This project explores NFL quarterback performance over the 2023–2025 seasons. The goal was to clean, aggregate, and visualize passing stats in a clear and meaningful way.

## What I did
- **Data Cleaning:**
    - Combined three seasons of raw QB CSV files into a single dataset. Standardized column names and filtered out players with fewer than 400 pass attempts to focus on regular starters
- **Analysis:**
    - Calculated average passing yards, touchdowns, and interceptions by season
    - Highlighted top 5 quarterbacks each season
- **Visualization:**
    - Created simple, easy-to-read line charts showing trends across seasons
## Why this project matters
While the analysis is straightforward, it demonstrates a clean workflow and practical skills:
- Importing and merging multiple datasets
- Filtering and aggregating meaningful data
-Basic visualizations that clearly communicate trends

## Tools & Skills Demonstrated
- Python & Pandas for data cleaning and aggregation
- Matplotlib for visualizing trends
